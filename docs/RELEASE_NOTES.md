# MacDPI 0.3.0 personal TUN preview

This ad hoc Universal 2 package adds a local TCP/UDP engine and per-session macOS administrator authorization without paid Apple Developer membership or a separately installed DPI tool. Enable selects Automatic setup and requires no Terminal paste. Ordinary DNS settings remain unchanged; eligible TLS origin repair uses validated Cloudflare answers. Disable releases the session's interface and routes.

The owner confirmed two-way Discord audio and remaining in a Roblox game on the development Mac/network. Automated live checks verified public HTTPS, the Discord API and an unauthenticated Gateway Hello over the tunnel. A 496-second resource sample measured 0.41% combined CPU and 130.33 MiB peak RSS. These results do not establish universal access, quantified voice/game latency, long-term reliability or UDP-specific circumvention.

ZIP, DMG and SHA-256 files are prepared locally. The package is not Developer ID signed or notarized; Intel/macOS 12 runtime and live failure/network-transition tests remain unverified. No GitHub release was published. [Current engineering report](PERSONAL_REPORT_0.3.0.md), [installation](../INSTALLATION.md), [verification](TUN_VERIFICATION.md).

## Preserved MacDPI 0.2.0 local review

MacDPI now bundles two Universal 2 system extensions. The transparent component handles eligible public TCP and UDP flows through macOS Network Extension. The optional DNS component handles eligible public lookups through Cloudflare DoH and preserves original DNS for local, split and interface-bound queries.

The native interface uses Mac-wide integration by default. A properly provisioned build follows official macOS approval and uses provider acknowledgements to report active routing and stop status. The ad hoc review artifact allows local diagnostics and cannot activate the system components. In that mode the loopback listener uses a per-launch credential. Existing ClientHello splitting remains available and TLS certificate validation stays with the client.

The review ZIP, DMG and checksum are local artifacts. Developer ID signing, notarization, installed lifecycle tests, native Discord voice and Roblox gameplay remain pending.
