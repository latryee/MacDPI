# Privacy

Personal TUN forwards captured public connections directly from the Mac. The helper's private journal records only route and interface ownership required for recovery. Traffic payloads, DNS contents and destinations are not written to a history. With optional Cloudflare DoH, eligible captured DNS questions go to Cloudflare. Private resolver paths and selected split domains remain with the system resolver. [Personal TUN DNS and routing](docs/PERSONAL_TUN.md).

MacDPI forwards to the original destination for most connections. Personal TUN's Automatic setup enables selective TLS origin repair. The repair uses System DNS for four fixed public service names when a session starts. For a suspected address and eligible visible Discord or Roblox TLS name, it sends that name to Cloudflare over HTTPS and may dial a verified address from that response. The Automatic setting leaves ordinary DNS on the system path. Manual settings let the user turn off repair or separately enable encrypted DNS for eligible captured queries. MacDPI has no traffic relay, advertising, telemetry, analytics, account system or update requests.

The transparent provider receives OS-supplied flow metadata and the numeric destination for eligible flows. The local proxy receives CONNECT host and port. Both handle encrypted tunnel bytes and may examine the plaintext first TLS ClientHello to select a record split. Origin TLS remains authenticated end-to-end. MacDPI does not record payloads, hostnames, destinations, passwords or browsing history. The app's aggregate counters and diagnostic snapshot remain in memory. Personal TUN also writes fixed caught-failure categories to the Mac's local unified log under subsystem `io.github.latryee.MacDPI`, category `TUN lifecycle`. These values are selected from a fixed enum; error descriptions, endpoints, DNS names, configuration values and traffic contents are excluded. macOS manages log access and retention. Controlled stop/cancellation is not logged as a worker failure. Abrupt termination may leave no application category. MacDPI does not upload these log entries. **Copy report** writes sanitized text to the clipboard only when requested; it does not collect the system log.

The app stores its chosen profile, DNS setting, split domains, Automatic setup/repair options, loopback port and resource limits in preferences. Approved integration scope is stored so the same scope can be enabled again. macOS stores the app-owned provider configurations for approved integration. A fresh app launch inspects status without requesting activation. Launch at login is opt-in. The loopback diagnostic credential stays in memory for the app launch, except when explicitly copied to the clipboard. The OS and clipboard managers can retain clipboard copies.

With Cloudflare DoH enabled, Cloudflare receives selected names and the requester's public IP through certificate-validated HTTPS. The local proxy caches A/AAAA results in bounded RAM until TTL or stop. The separate DNS provider forwards eligible ordinary DNS queries and stores no persistent or provider-level answer cache. Local, split and interface-bound queries use their original resolver. A failed encrypted request remains a failed request. [Cloudflare resolver privacy](https://developers.cloudflare.com/1.1.1.1/privacy/public-dns-resolver/).

The optional web window on macOS 14 and later uses a nonpersistent WebKit data store. Sites can set session cookies and load their own resources. The window denies microphone and camera requests and closes on stop. MacDPI adds no site tracking.

The separate real-network check requires an explicit external-request acknowledgement. It contacts fixed public Discord and Roblox endpoints without credentials. It is excluded from normal local tests and CI. The existing results belong to the historical 0.1.0 local proxy test. [Historical scope](docs/REAL_NETWORK_VALIDATION.md).
